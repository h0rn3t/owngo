## P5.2 Байти доведеного `implicit`

`FreeAccounted`, `DecAccounted` і `NoteAlloc` отримують довжину буфера. Конкатенація і перетворення `string`/`[]byte` виділяють рівно стільки байтів. `append`, який цей прохід сам виділяє, теж. `append`, який лишає `GrowSlice`, у підсумок не входить: `cap` може перевищувати `len`. `[]rune` у підрахунок не входить.

Команди з кореня, LLVM 23 і LLD першими в `PATH`, `LLGO_ROOT=$PWD`. Обидві дали код 0.

`go run ./cmd/llgo run -tags owngo ./owngo/bytes/imconcat` — одна конкатенація `"abcd" + "efgh"`. Володіння `static`, тож ці 8 байтів ідуть у `freed`. Живий `static` після виклику такий самий, як до нього:

```
owngo freed 144
owngo live static 984
owngo live rc-local 1889
owngo live rc-shared 368
owngo live pinned 2892
```

`go run ./cmd/llgo run -tags owngo ./owngo/bytes/imheld` — та сама конкатенація, передана в параметр `func(string)`. Для v1 це `rc-local: call`: `FreeAccounted` і `DecAccounted` немає, 8 байтів лишаються в `live rc-local`. `freed` і живий `static` не змінюються:

```
owngo freed 136
owngo live static 984
owngo live rc-local 1897
owngo live rc-shared 368
owngo live pinned 2892
```

Різниця між прогонами — 8 байтів: у першому вони в `freed` (144 − 136), у другому в `live rc-local` (1897 − 1889). Живий `static` в обох прогонах 984. Сама програма перевіряє цей приріст навколо місця і виходить з кодом 0 лише коли він дорівнює 8.

Поруч із заміром P2.3 і P2.4 лишаються 819 968 312 байтів `implicit` двох рядків: 17.7% двох рядків і 11.2% профілю 17 сервісів. Звільнені фікстурою 8 байтів, і 144 байти всього процесу на першому прогоні, менші за половину того профілю (3 669 927 840). Цього кроку це досить. Профілі наново не знімались.
