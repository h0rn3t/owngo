# Звіт фази 1

Профілі й місця census — ті самі, що в P0.8 і P0.10: юніт-тести `go test -count=1 -memprofilerate=1`, без `//go:build integration` і без окремого прогону бенчмарків. Повторний census на тих самих клонах дає той самий рядок поза census, що в `REPORT-PHASE0.md`.

## P1.1 Розклад байтів поза census

`Outside` бере вибірку, яку `Weigh` лишає поза census, і кладе її в один ківш за першим кадром від листа стека, який не належить пакету `runtime`. До пакета `runtime` входять файли `GOROOT/src/runtime` і каталоги `internal`, `cgo`, `race`, `msan`, `asan`, `secret`. `runtime/pprof` та інші бібліотечні підпакети лишаються стандартною бібліотекою.

- Файл `*_test.go` або згенерований `_testmain.go` — тести, навіть у `GOROOT` чи в залежності. `_testmain.go` — це `main` тестового бінарника, не модуль поза `-dir`.
- Інакше `GOROOT/src` — стандартна бібліотека.
- Інакше каталог `-dir` — нетестовий файл модуля, рядок якого не збігся з місцем.
- Інакше — модуль поза `-dir`.

П'ятий рядок не входить у чотири класи з `PLAN.md`. Він є, щоб сума ківшів дорівнювала рядку поза census. Відсоток ківша ділить на байти цього рядка. Останній стовпець — частка всього рядка від профілю. Округлення до одного знака, як у `FormatWeights`.

## P1.5 Байти, що пройшли через `free`

Лічильник на виході процесу (`os.Exit` → `ReportExit`): байти, які `FreeAccounted` забрав у `free`, і байти живих місць за категорією census v1 (строгий режим інтерфейсів). Обліковується куповий `new` із відомим `SizeOf`. `stack` лишається на стеку.

Команди з кореня, LLVM 23 і LLD першими в `PATH`, `LLGO_ROOT=$PWD`. Обидві дали код 0.

`go run ./cmd/llgo run -tags owngo ./owngo/bytes/static` — одне місце `new([8]byte)`, яке не виходить із функції:

```
owngo freed 112
owngo live static 984
owngo live rc-local 1768
owngo live rc-shared 368
owngo live pinned 2892
```

`go run ./cmd/llgo run -tags owngo ./owngo/bytes/rclocal` — те саме місце, повернуте з функції:

```
owngo freed 104
owngo live static 984
owngo live rc-local 1776
owngo live rc-shared 368
owngo live pinned 2892
```

Різниця між прогонами — 8 байтів: у першому вони в `freed` (112 − 104), у другому в `live rc-local` (1776 − 1768). Сама програма теж перевіряє цей приріст навколо місця і виходить з кодом 0 лише коли він дорівнює 8.

Поруч із заміром фази 0: `static` після v1 — 12.1% приписаної купи (277 779 290 байтів); поза census — 67.6% профілю (4 963 968 984 із 7 339 855 680). Звільнені фікстурою 8 байтів, і 112 байтів усього процесу на першому прогоні, менші за половину того профілю. Цього кроку це досить.
